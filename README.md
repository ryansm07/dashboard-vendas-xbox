# 🎮 Xbox Game Pass Sales Dashboard

Este projeto tem como objetivo analisar dados de assinaturas do Xbox Game Pass, utilizando Excel para construção de dashboards interativos e geração de insights sobre vendas, comportamento dos clientes e receita.

> 📌 Projeto desenvolvido com base em uma ideia proposta pela DIO (Digital Innovation One) como treinamento em Excel com foco na criação de dashboards.

---

## 📊 Sobre o projeto

A base de dados contém informações relacionadas às assinaturas do serviço, incluindo:

- Tipo de plano (Core, Standard, Ultimate)  
- Tipo de assinatura (Mensal, Trimestral, Anual)  
- Uso de renovação automática  
- Aquisição de addons (EA Play e Minecraft)  
- Aplicação de cupons  
- Valor total das assinaturas  

A partir desses dados, foi desenvolvido um dashboard com foco em análise exploratória e suporte à tomada de decisão.

---

## 🎯 Objetivos

- Analisar o faturamento total e ticket médio  
- Identificar os planos mais rentáveis  
- Avaliar o impacto de cupons na receita  
- Entender o comportamento dos clientes (renovação automática e addons)  
- Comparar a performance entre diferentes tipos de assinatura  

---

## 📈 Funcionalidades do Dashboard

- **Indicadores-chave (KPIs):**
  - Faturamento total  
  - Total de clientes  
  - Ticket médio  
  - % de renovação automática  

- **Gráficos:**
  - Receita por plano  
  - Distribuição de assinaturas  
  - Evolução da receita ao longo do tempo  

- **Análises adicionais:**
  - Tabelas dinâmicas para addons (EA Play e Minecraft) (em desenvolvimento)
  - Segmentações (filtros) interativas (em desenvolvimento)

---
